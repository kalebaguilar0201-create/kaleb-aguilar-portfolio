# Machine Learning & Computational Science Portfolio

I am a Physics Engineer and M.Sc. student in Computer Science focused on machine learning systems, probabilistic modeling, and computational simulation.

This repository contains applied projects spanning:

- Scientific computing and GPU simulation
- Machine learning systems and optimization
- Probabilistic and statistical learning
- Deep learning architectures
- Data analysis and real-world datasets

---
## Projects

### 1. Computational Physics & High-Performance Machine Learning
**Abstract:** Stochastic simulation of physical systems with GPU acceleration for large-scale numerical experiments in semiconductor growth.

- **Tools:** Python, Numba, CUDA, NumPy
- **Focus:** Monte Carlo simulation, parallel computing, physical modeling, performance optimization, Molecular Beam Epitaxy (MBE)

---

### 2. Machine Learning Systems & Optimization
**Abstract:** Development of end-to-end machine learning systems that combine deep learning, constrained optimization, and data engineering for real-world applications.

- **Tools:** PyTorch, SciPy, Flask, REST APIs, Pandas
- **Focus:** Attention neural networks, Bayesian-inspired optimization, L-BFGS-B, Projected Gradient Descent, performance attribution, deployment

---

### 3. Probabilistic Machine Learning
**Abstract:** Implementation of probabilistic forecasting methods based on Random Forests for uncertainty estimation and interpretable prediction.

- **Tools:** Python, Scikit-learn, NumPy, Pandas, Matplotlib
- **Focus:** Quantile Regression Forests, probabilistic forecasting, weight matrix computation, Top-k sparsification, uncertainty modeling

---

### 4. Deep Learning
**Abstract:** Collection of deep learning implementations covering computer vision, sequence modeling, and generative learning.

- **Tools:** PyTorch, TensorFlow, Hugging Face Transformers, OpenCV
- **Focus:** Image classification, sequence learning, conditional image generation, transfer learning, representation learning

---

### 5. Data Analysis & Statistical Modeling
**Abstract:** Exploratory analysis of large demographic datasets to identify statistical trends and generate actionable insights through visualization.

- **Tools:** Python, Pandas, NumPy, Matplotlib
- **Focus:** Exploratory Data Analysis (EDA), statistical analysis, feature engineering, data visualization
